# Qube: OpenQASM 상태벡터 양자 회로 에뮬레이터

**OpenQASM 2.0 Compiler & 2^N-Dimensional State-Vector Quantum Circuit Emulation Kernel**

Qube는 OpenQASM으로 작성된 양자 회로를 고전 컴퓨터에서 정확히 계산하는 상태벡터 방식의 에뮬레이터입니다. 양자 알고리즘을 실제 하드웨어에 올리기 전에 논리적 정합성을 검증하는 용도를 목표로 합니다.

## 🔬 What Qube Does

- **OpenQASM 2.0 입력:** 텍스트로 작성된 양자 회로를 파싱해 게이트 연산으로 변환합니다.
- **2^N 상태벡터 계산:** N개 큐비트의 2^N개 복소 진폭을 모두 메모리에 두고 게이트를 적용합니다. 근사 없이 정확한 결과를 얻는 대신, 메모리와 계산 시간이 큐비트 수에 따라 지수적으로(큐비트 하나당 2배) 늘어납니다.
- **국소 게이트 적용:** 2^N × 2^N 전체 연산자 행렬을 만들지 않고, 게이트가 작용하는 큐비트에 해당하는 진폭 쌍만 갱신합니다. 그래서 게이트 하나의 비용은 O(2^N)입니다.
- **관측값 추출:** 상태벡터로부터 각 큐비트의 파울리 Z 기대값을 계산합니다.

### 범위와 한계

- 노이즈가 없는 **이상적인** 양자 회로를 계산합니다. 실제 하드웨어의 결어긋남(decoherence)이나 게이트 오류를 모사하지 않으며, 이를 극복하거나 대체하는 기술이 아닙니다.
- 상태벡터 방식이므로 일반적인 PC에서 다룰 수 있는 큐비트 수는 대략 20~30개 수준입니다(메모리에 따라 다름).
- 크래머-라오 하한(CRB) 관련 모듈은 재설계 중이며, 상세 내용은 추후 공개할 예정입니다.

## 📊 Example: GHZ State (N=10)

10큐비트 GHZ 상태 (|00…0⟩ + |11…1⟩)/√2 를 OpenQASM 회로(H 1개, CNOT 9개)로 생성한 결과입니다.

| 항목 | 이론값 | Qube 결과 |
|---|---|---|
| P(\|00…0⟩), 인덱스 0 | 0.5 | 0.50000 |
| P(\|11…1⟩), 인덱스 1023 | 0.5 | 0.50000 |
| 나머지 1,022개 상태의 확률 합 | 0 | 0.00000 |
| 전체 확률 합 | 1 | 1.00000 |

노이즈 없는 이상적 계산이므로 이론값과 일치하는 것은 구현이 올바르다는 확인이며, 다른 시뮬레이터 대비 성능 우위를 뜻하지는 않습니다.

## 🎯 Target Use Cases

- **양자 알고리즘 검증:** 하드웨어 실행 전 회로의 논리적 정합성 확인
- **교육과 프로토타이핑:** 상태벡터 전체를 직접 들여다볼 수 있는 학습·실험 환경
- **하드웨어 가속 (개발 목표):** GPU, FPGA/ASIC 기반 가속은 향후 연구 목표이며 현재 구현된 기능이 아닙니다.
